# RedSkill cover visual brief / RedSkill 封面视觉说明

## Purpose / 用途

`public-assets/promotion/patent-jun-redskill-cover.png` is a 4:5 generated cover candidate for a RedSkill listing and a small GitHub README visual card. It is a fictional editorial illustration, not a real patent drawing, source document, test setup, or measured apparatus.

`public-assets/promotion/patent-jun-redskill-cover.png` 是用于 RedSkill 条目和 GitHub README 小型视觉卡片的 4:5 生成封面候选图。它是虚构的编辑式插图，不是真实专利图纸、来源文件、试验装置或实测设备。

## Prompt / 提示词

> Create a vertical 4:5 promotional cover illustration for an open-source evidence-first patent drafting workflow called Patent Jun. Use the attached Patent Jun character as the consistent visual reference: an adult, gender-neutral 2.5D engineering guide with round glasses, dark navy and teal work jacket, clipboard and magnifying glass. Place the character on the left third, looking at a clean floating evidence workflow board on the right: four abstract cards connected by a teal line, with tiny geometric marks only and no readable words or numbers. The board should suggest source, evidence, claim limitation, and human review without exposing any real patent matter. Warm paper-white background, engineering navy, evidence teal, review coral accents, restrained editorial product illustration, generous clean margins, high contrast, suitable for a Xiaohongshu RedSkill listing cover and safe for a GitHub README. No Chinese or English text, no logos, no seals, no government symbols, no legal scales, no patent drawings, no confidential data, no measurements, no performance claims, no watermark.

## Negative prompt / 禁用项

Readable text, fake application numbers, dimensions, performance charts, test results, patent drawings, client names, suppliers, real people, official seals, government emblems, gavels, legal scales, trophies, third-party logos, watermarks, UI screenshots, confidential notes, or any claim of approval or grant.

可读文字、虚构申请号、尺寸、性能图表、试验结果、专利图纸、客户名称、供应商、真实人物、官方印章、政府纹章、法槌、法律天平、奖杯、第三方标识、水印、界面截图、保密笔记，以及任何授权或通过暗示。
