> **所有以下案例均为 synthetic（合成）案例。** 它们不是客户材料、不是已提交案件，也不支持授权、可专利性、侵权、有效性或任何法律结论。

## 使用案例时的共同规则

1. 保留 `synthetic` 标签和来源字段；不要替换为真实组织、人员、客户或未公开参数。
2. 先复现校验结果，再阅读解释；输出只是内部审阅包候选。
3. 如果把自己的材料带入工作流，先做保密扫描并取得适当专业人员复核。
