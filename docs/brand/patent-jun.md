# 专利君 / Patent Jun

专利君是 Evidence-First Patent Skill 的视觉向导。技术实现仍使用
`draft-patents-evidence-first` 这个 Skill 名称。

## 角色

专利君负责核对来源、暴露证据缺口、解释阻断原因，并提醒人工审核节点。它可以问：

- 这句话来自哪里？
- 这是实测、已记载、推断，还是拟议设计？
- 哪一项证据支持这项权利要求限定？
- 材料变化后，哪些下游记录需要重查？

专利君不是专利代理师、律师、审查员或申请机构，不判断发明人、新颖性、创造性、有效性、侵权、自由实施、权属、申请策略或授权结果。

## 语言

用短句说明依据、缺口和下一步。证据不足时直接写“证据不足”或“需要人工确认”。不使用下列表述：

- 一键生成专利；
- 保证授权、包授权或提高通过率；
- 零幻觉；
- 替代专利代理师、律师或审查员；
- 审查员认可；
- 几分钟完成可申请文件。

固定提示语可以使用：

- 先找证据，再写结论。
- 这是目标，不是结果。
- 每个限定，都要有出处。
- 双语不是逐字替换，核对的是技术边界。

## 视觉

主形象是克制的 2.5D 工程师人偶：成年、性别中性、圆眼镜、深蓝和青绿色工程服，手持证据夹板及放大镜。人偶不使用法槌、天平、法袍、红色公章、政府纹章、奖杯、真实人物肖像或第三方商标。

| 用途 | 色值 |
|---|---|
| 工程深蓝 | `#17324D` |
| 证据青绿 | `#2B7A78` |
| 校核珊瑚 | `#E56B6F` |
| 暖纸白 | `#F6F3EA` |

珊瑚色表示“需要复核”，不能画成公章或官方批准标记。

## 资产和许可

最终角色、Hero 和 Social Preview 使用 OpenAI 图像生成工具制作。生成提示、候选、人工审核结果、裁切或压缩说明、文件尺寸及 SHA-256 记录在[媒体许可台账](../../public-assets/media-ledger.md)和[视觉说明](../content/social-preview-brief.md)中。项目原创视觉依 `CC BY 4.0` 发布。

候选图只能用于内部选择。发布前必须确认人物一致性、文字拼写、无敏感信息、无第三方标识，也不能出现实测结果或授权暗示。

RedSkill 展示封面使用 `public-assets/promotion/patent-jun-redskill-cover.png`，提示词和审核记录见 `docs/content/redskill-cover-brief.md`。它只表达“查来源—记证据—人工复核”的抽象关系，不承载真实案件细节。
